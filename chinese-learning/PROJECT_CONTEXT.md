## 项目定位

为真实用户制作的三语中文学习网站，**纯静态前端**（原生 HTML + minified JS + JSON，无构建），部署于 GitHub Pages。不是技术练习项目，是给真人每天使用的产品。

- 代码库：`D:\Claude\projects\cycle-tracker\chinese-learning\`
- 线上：`https://darkheaven1419-debug.github.io/cycle-tracker/chinese-learning/`
- 技术栈：`index.html` + `js/*.js`（6 个脚本）+ `data/*.json` + `css/learning.css`
- 制作者：Barry（开发者）→ 使用者：Anđela（塞尔维亚女友）

## 用户画像

- Anđela：完全不懂中文，不用汉字键盘，主要语言塞尔维亚语。
- 移动端为主、碎片时间使用；目标是轻松坚持、有成就感。
- 需要「有人认真为她设计过」的感觉：**好用、舒服、有趣**。

## 三语角色（严格遵守）

| 语言 | 角色 | 要求 |
|---|---|---|
| **sr**（Serbian） | 主语言 | 必须自然、完整、地道（Serbian 阴性变格等细节重要） |
| **en**（English） | 辅助 | 备用；可紧凑缩写 |
| **zh**（Chinese） | 学习目标 | 教学语言，内容本身即学习材料 |

- 不允许莫名其妙的语言混杂；语言切换必须可靠；学习进度不因切换语言/刷新丢失。
- 三语文案通过 `_()` 映射函数，语言变量 `lang`（sr 默认）。

## 产品目标

1. Anđela 每次打开都感到「很好用、很舒服、很有趣」。
2. 最终追求「真的很好用」，不是「功能全部通过测试」。
3. 学习路径真实有效：180 课 / 6 阶段（Faza），循序渐进（认字 → 理解 → 选择 → 自己输入）。

## 核心设计原则

1. **不大规模重构**、不改变已正常工作的核心功能、不随意改视觉风格。
2. 优先复用现有组件/函数/数据结构。
3. 修改前先读代码理解架构；每阶段完成都测试。
4. 涉及产品设计变更**先问用户**，不擅自决定。
5. 不删看似没用的代码（除非确认无引用）；**不一次改所有问题**。
6. 每完成一个阶段按固定结构汇报（改了什么/为什么/测试/结果/新风险/下一阶段），**等确认再继续**。

## UX 原则

- 一个状态 → 一个主 CTA + 学习路径；不做按钮海洋、不重复动画、不每次打开提醒。
- 零基础用户不能遇到「我不会」时刻（例：Faza 1 不要求手写汉字）。
- 温和反馈优先：测验失败不指责（sr「Nisi prošla — ali svaka vežba te približava cilju!」）。
- 即时成就要真实，**不伪造数据**。
- 移动端：大点击区域（≥44px）、不横向溢出、无复杂动画。
- 先做只读审查出报告，等确认后再实现。

## 技术修改原则

- **字节级精确替换**优先：每处锚点 `count==1` 校验，失败不写盘。
- 修改前备份到 `_tmp_*_backup*`；执行脚本用 `_tmp_*_apply.js`（非部署文件）。
- 数据结构尽量**不新增字段**（优先复用现有 zh/py/sr/en 字段）。
- minified 文件引号/边界需谨慎，勿臆断锚点归属。

## 测试原则

- 每个 Phase/UX 有专项测试 + 全量回归（Phase1/2/3 + UX）。
- 测试基建见 `tests/verify_ux.test.js` 头部注释；回归命令见 `OPTIMIZATION_STATUS.md`。
- 用户明确授权：**不要因成本提示缩减测试、回归、审查、质量检查**。

## 明确禁止的行为

- 顺手做当前任务圈定范围之外的改动（改 UI/文案/数据/功能）。
- 删除或永久移除「写汉字」能力（学习难度渐进，仅 Faza 1 改认读选择题，Faza 2-6 保留输入）。
- 未确认就实现待办项（如 UX-10B、UX-10 报告 P2-P4）。
- 伪造学习数据 / 未经授权调用外部服务。
- 一次改所有问题；跳过测试直接交付。
