## 二、180课课程体系

### 2.1 六阶段概览

```
阶段 1: 🏛️ 拼音基石 (第1-30课)   → 零基础入门，拼音/声调/笔画/基本问候
阶段 2: 🗣️ 日常生活 (第31-60课)  → 餐厅/购物/问路/交通/家庭/时间
阶段 3: 🌆 社交出行 (第61-90课)  → 租房/求职/恋爱/约会/社交媒体
阶段 4: 💬 情感对话 (第91-120课) → 表达观点/争论/安慰/祝贺/中塞文化对比
阶段 5: 📝 读写进阶 (第121-150课) → 汉字部首/成语故事/阅读/简单写作
阶段 6: 🎯 流利表达 (第151-180课) → 辩论/演讲/深度文化/中文思维
```

### 2.2 每课结构（30分钟）

| 环节 | 时长 | 内容 |
|------|------|------|
| 📝 复习 | 5分钟 | 上节课重点回顾 + 快速小测 |
| 📖 新词 | 10分钟 | 5-10个生词（汉字+拼音+塞语） |
| 📐 语法 | 5分钟 | 1-2个语法点 + 例句 |
| ✏️ 练习 | 5分钟 | 互动练习（选择/连线/填空/发音） |
| 🏮 文化 | 3分钟 | 中国/塞尔维亚文化小贴士 |
| ✅ 测验 | 2分钟 | 3-5题快速测验 |

### 2.3 阶段1详细示例（第1-30课）

| 课号 | 主题 | 核心词汇示例（汉字/拼音/塞语） |
|------|------|--------------------------|
| 1 | 欢迎和汉语概览 | 你好 nǐ hǎo/Zdravo, 谢谢 xièxie/Hvala, 我 wǒ/Ja, 是 shì/Biti |
| 2 | 声母(一) bpmf dtnl | 爸爸 bàba/Tata, 妈妈 māma/Mama, 朋友 péngyou/Prijatelj |
| 3 | 声母(二) gkh jqx zhchshr | 高兴 gāoxìng/Srećan, 中国 Zhōngguó/Kina, 吃 chī/Jesti |
| 4 | 韵母(一) aoe iuü | 爱 ài/Voleti, 在 zài/Biti u, 来 lái/Doći, 买 mǎi/Kupiti |
| 5 | 韵母(二) 鼻韵母 | 你 nǐ/Ti, 他/她 tā/On/Ona, 很 hěn/Veoma |
| 6 | 四声+轻声 | 妈mā/麻má/马mǎ/骂mà, 吗 ma, 说 shuō/Govoriti |
| 7-8 | 基本笔画 | 我/你/他/的/人/大/小/上/下/中/水/火/山/日 |

## 三、学习进度与成就系统

### 3.1 解锁机制

```
阶段1 (1-30)  → 全部开放
阶段2 (31-60) → 完成阶段1 80%课程 + 阶段测试≥60分
阶段3 (61-90) → 完成阶段2 80%课程 + 阶段测试≥65分
阶段4 (91-120)→ 完成阶段3 80%课程 + 阶段测试≥70分
阶段5 (121-150)→ 完成阶段4 80%课程 + 阶段测试≥70分
阶段6 (151-180)→ 完成阶段5 80%课程 + 阶段测试≥75分

每课解锁下一课条件: 前一课已完成
允许跳课: 每阶段最多3课，跳过的需在阶段测试前补齐
```

### 3.2 打卡系统

| 条件 | 奖励 |
|------|------|
| 连续3天 | 🔥 火花徽章 + 双倍经验 |
| 连续7天 | ⭐ 一周之星 |
| 连续15天 | 🌙 半月成就 |
| 连续30天 | 💎 满月成就 |
| 连续100天 | 🏆 百天传奇 |

每月3次补签机会，可设置固定学习提醒（如每晚19:00）。

### 3.3 成就徽章（20个）

| 徽章 | 名称 | 条件 |
|------|------|------|
| 🎯 | 第一步 | 完成第1课 |
| 🌟 | 拼音大师 | 阶段1拼音测试满分 |
| 💪 | 百词突破 | 掌握100词 |
| 🔥 | 7天打卡 | 连续7天学习 |
| 📚 | 50课完成 | 完成50课 |
| 🏅 | 满分达人 | 10次测验满分 |
| 🏛️ | 阶段1-6毕业 | 完成对应阶段（共6个） |
| 🎓 | 全部完成 | 完成180课 |
| 💎 | 30天打卡 | 连续30天学习 |
| ⏱️ | 10小时 | 累计学习10小时 |
| 🕐 | 50小时 | 累计学习50小时 |
| 🀄 | 成语收集者 | 掌握10个成语 |
| 🏮 | 文化探索者 | 完成全部文化小贴士 |
| 💕 | 中文之恋 | 完成全部伴侣任务 |

### 3.4 艾宾浩斯遗忘曲线复习

| 复习次数 | 间隔 | 说明 |
|---------|------|------|
| R1 | 1天后 | 次日复习 |
| R2 | 3天后 | 隔两天 |
| R3 | 7天后 | 一周后 |
| R4 | 14天后 | 两周后 |
| R5 | 30天后 | 一月后 |

复习状态标识：🔴 超期 → 🟡 今日到期 → 🟢 3天内 → ⚪ 无需复习

### 5.1 文件变更

**新增文件:**
```

```

**修改文件:**
```

index.html              ← panel-culture → panel-chinese

```

### 5.2 数据流

```
data/lessons.json ──fetch──→ LESSONS_CACHE (内存)
                                   │
用户交互 ──→ lesson-engine.js ──→ localStorage (进度持久化)
    │              │                        │
    │              ├── 成就判定 ──→ 解锁动画  │
    │              │                        │
    │              └── 复习计算 ──→ 提醒UI   │
    │                                       │
    └── GitHub API ──→ 跨设备同步 (复用现有机制)
```

## 七、设计亮点

1. **渐进式学习曲线**：从拼音→单词→句型→对话→阅读→流利，180课科学进阶
2. **中塞融合特色**：每课融合中塞文化对比，为 Barry & Anđela 量身定制
3. **游戏化激励**：打卡、徽章、积分、解锁，保持学习动力
4. **科学复习**：艾宾浩斯遗忘曲线算法，智能推送复习
5. **离线可用**：PWA + localStorage，随时随地学习
6. **双人互动**：伴侣任务（用中文对 Anđela 说三句话），学习不只是一个人的事
7. **移动优先**：触屏友好、大按钮、滑动手势、震动反馈
